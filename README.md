# Gamified Student Productivity App 🚀

An interactive MERN stack web application designed to help students build consistent study habits, track daily tasks, earn XP, level up, and maintain productivity streaks.

---

## 🛠️ Tech Stack

* **Frontend:** React, Vite, Axios
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas (Mongoose ODM)
* **Authentication:** JSON Web Tokens (JWT) & Bcrypt

---

## 📑 Core Features

* **User Authentication:** Secure user registration, password hashing (`bcrypt`), and token-based session persistence.
* **Quest Log (Task Management):** Create, categorize (Academic, IT Project, Personal), prioritize, and complete tasks to earn XP.
* **Leveling System:** Dynamic user leveling calculated automatically based on total earned XP.
* **Streak & Habit Tracker:** Track consecutive daily completions for custom habits and core productivity routines.
